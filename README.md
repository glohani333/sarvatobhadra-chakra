# सर्वतोभद्र चक्र (Sarvatobhadra Chakra)

Basic Flutter app for **Sarvatobhadra Chakra** - a classical Vedic astrology tool.

## Current Features
- 9×9 Sarvatobhadra grid
- Sample transit planet positions
- Nakshatra labels on outer ring
- Color coded planets

## How to Run / Build APK
1. Install Flutter SDK
2. Clone this repo
3. Run:
   ```bash
   flutter pub get
   flutter run
